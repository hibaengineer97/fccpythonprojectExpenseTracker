
# fccpythonprojectExpenseTracker

A Python project consisting of an Expense Tracker from FreeCodeCamp - Scientific Computing with Python.

# Scientific Computing with Python - FreeCodeCamp

## About

This project was completed as part of the FreeCodeCamp "Scientific Computing with Python" course. It is a command-line expense tracker that allows users to add expenses, display all expenses, calculate the total amount spent, and filter expenses by category.

## Features

- Add new expenses with an amount and category.
- Display all recorded expenses.
- Calculate the total expenses.
- Filter expenses by category.
- Store expense data using Python dictionaries inside a list.

## Learning Notes

Through this project, I strengthened my understanding of several important Python concepts:

- **Functions (`def`)** to organize the program into reusable blocks.
- **Dictionaries** to store each expense as key-value pairs (`amount` and `category`).
- **Lists** to manage multiple expense records.
- **`input()`** to interact with the user through the command line.
- **`if`, `elif`, and `else`** statements to build a menu-driven application.
- **`lambda` functions** to write concise anonymous functions.
- **`filter()`** to select expenses belonging to a specific category.
- **`map()`** to process expense amounts before calculating the total.
- **Loops (`while` and `for`)** to repeatedly display the menu and iterate through expenses.

This project helped me gain more confidence in writing interactive Python programs and applying functional programming concepts such as `lambda`, `map()`, and `filter()`.
